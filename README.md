# Master-English-

تطبيق «كلمة» — تطبيق ويب عربي (RTL) في ملف واحد `index.html` لتعلّم مفردات الإنجليزية، بأسلوب: كلمات قليلة كل يوم، مع تكرار متباعد (Spaced Repetition).

## المحتوى — 197 كلمة

| المجموعة | العدد |
|---|---|
| كلمات أساسية | 12 |
| كلمات مهمة | 50 |
| إضافة بخط اليد (boast) | 1 |
| استكمال الوحدة الأولى | 51 |
| الوحدة الثانية · وقت الفراغ | 60 |
| الوحدة الثالثة · المذاكرة والمهارات | 23 |

كل كلمة فيها: المعنى بالعربي، نوع الكلمة، جملة مثال بالإنجليزية وترجمتها.
و**192 كلمة** ليها خانة **Synonyms (مرادفات)** و**175 كلمة** ليها **Antonyms (أضداد)** — بتظهر في كروت الحفظ وفي القاموس، ويمكن البحث بيها، وفيها أسئلة مخصوصة في الاختبار.

## الأقسام

الرئيسية · كروت الحفظ · اختبر نفسك · وصّل الكلمات · مراجعتي · **خانة الجرامر** · قاموس الكلمات (بحث وفلترة حسب المجموعة والحالة).

### اختبر نفسك — خمس أنواع أسئلة

| النوع | الفكرة |
|---|---|
| معنى الكلمة | تختار المعنى العربي الصح من 4 اختيارات |
| من العربي للإنجليزي | تشوف المعنى وتختار الكلمة |
| كمّل الجملة | الكلمة ناقصة من جملة الكتاب |
| **اختار المرادف** | تختار أقرب كلمة لنفس المعنى (Synonyms) |
| **اختار العكس** | تختار الكلمة اللي معناها عكسها (Antonyms) |

في أسئلة المرادف والعكس، الاختيارات بتتجمّع من مرادفات وأضداد كل الكلمات، والمشابهات القريبة بتتقفل كمشتّتات عشان السؤال يبقى عادل، وكل إجابة بتعرض معناها وجملتها ومرادفاتها.

### خانة الجرامر

12 درس جرامر بشرح عربي مبسّط: المضارع البسيط والمستمر · الماضي البسيط والمستمر · المضارع التام · المستقبل · المقارنة والتفضيل · المعدود وغير المعدود والكميات · الأفعال الناقصة · المبني للمجهول · الجمل الشرطية · الجمل الموصولة · المصدر والـ ing · أدوات الربط.

كل درس فيه: قاعدة مختصرة، جدول مقارنات، أشهر غلطة، **و48 سؤال تدريب** بإجابة فورية وشرح السبب. وفي زر لتدريب عشوائي شامل، ونتيجة التدريب بتتحفظ معاك.

## التشغيل

التقدّم يُحفظ محليًا في المتصفح (`localStorage`)، والتطبيق يعمل بفتح `index.html` مباشرة دون أي خادم أو مكتبات خارجية.
